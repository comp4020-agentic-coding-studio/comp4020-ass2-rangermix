## Someone says "how are you?"

You have about a second to reply.

The correct reply is not an answer.

## The documentation exists

Schegloff set out to "ascertain rules" for how conversations open, and named properties like *conditional relevance*.

<span class="source">Schegloff (1968), American Anthropologist 70(6), 1075–1095</span>

- Only the abstract was checked. Name the term; don't define it from the paper.

## Talk whose job is the relationship

"Phatic communion": Malinowski's 1920s term for talk that maintains the connection rather than carrying information.

It's better understood as negotiated than as a fixed, empty type.

<span class="source">Coupland, Coupland & Robinson (1992), Language in Society 21(2)</span>

```notes
- "You aren't being asked for data. You're being asked to confirm the connection is up."
```

## Valid replies

| Reply | Token | Returns it? | Closes? |
| --- | --- | --- | --- |
| Good, you? | positive | yes | after one more turn |
| Not bad, you? | neutral | yes | after one more turn |
| Yeah, fine. | neutral | no | immediately |
| Surviving. | a joke | no | if said lightly |

The reply SHOULD return the request when there's time for one more turn.

```notes
- Deadpan the RFC 2119 keywords. Don't wink.
```

---

{/* _class: quote */}

"Honestly, I've had a rough week. I haven't slept properly since Tuesday…"

A **correct answer** to the question as asked, and a **nonconforming reply** under this protocol.

```notes
- It isn't wrong; it's a different message. It switches the listener into hearing about troubles, which they hadn't budgeted for.
- "Some of you have watched someone's face change after this and not known why. That's why."
```

## When it's a real question

The asker:

- **stops moving**
- **asks twice** ("no, how are you actually?")
- **asks somewhere private**

These are the course's working rules, not a finding. Thursday's lab tests them.

## Why nobody handed it to you

If you run the handshake without effort, the spec read as the obvious. That's because you've run it ten thousand times, not because it is simple.

If it's felt strange for years, you were right that it had rules. That's a documentation problem, not a problem with you.

```notes
- Speak to both halves of the room here, one after the other, without ranking them.
```
