# Submitting work

> **This course prototype does not accept submissions.** There is no live
> upload service or learning-system link. The steps below describe the intended
> process for an enrolled class.

## Intended submission process

1. Open **SLOP1562 / NT101 → Assessment** in the university learning system,
   using the sign-in link supplied with enrolment.
2. Choose the task. For the Field Journal, also choose the teaching week;
   each week's entry is a separate submission.
3. Attach the work required by the brief. Check that the uploaded file opens
   and is the version you meant to send.
4. Select **Submit**, then check the receipt for the task, week if applicable,
   filename and submission time. Keep the receipt. A saved draft or a selected
   file is not a completed hand-in.

The briefs contain the required work and deadlines:

- [Field Journal](/assessments/field-journal/) — one file for each teaching
  week from week 2 onwards; its page lists every Sunday deadline.
- [Protocol Specification](/assessments/protocol-specification/) — the
  specification and its conformance tests.
- [Interoperation Report](/assessments/interoperation-report/) — each partner
  hands in their own report, including the agreed protocol.
- [Capstone](/assessments/personal-protocol-document/) — name your chosen route
  at the top of the document.

## If something goes wrong

An upload failure goes to your tutor through the
[help contact route](/policies/#asking-for-help). Give the task, the time you
tried and the error message. Don't attach your assessment to the email; ask
for the upload route to be restored or an alternative to be arranged.

For more time, use the [extension policy](/policies/#extensions). It includes
the separate rule for the Field Journal.
